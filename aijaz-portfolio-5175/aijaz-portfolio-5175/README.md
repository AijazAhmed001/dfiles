# Aijaz Ahmed Portfolio

A clean, responsive, multi-page React portfolio with separate JSX and CSS files.

## Run the project

```powershell
cd aijaz-portfolio-5175
npm install
npm run dev
```

Open:

```text
http://localhost:5175
```

## Build for production

```powershell
npm run build
npm run preview
```

## Main structure

```text
src/
├── components/
├── data/
├── pages/
├── styles/
├── App.jsx
└── main.jsx
```

## Customize

- Personal content: `src/data/portfolioData.js`
- Page content: `src/pages/`
- Colors and spacing: `src/styles/variables.css`
- Resume file: replace `public/Aijaz-Ahmed-Resume.pdf`
- Profile artwork: replace `public/profile-illustration.svg`

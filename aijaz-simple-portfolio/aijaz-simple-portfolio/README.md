# Aijaz Simple Portfolio

A clean single-page portfolio built with React, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Main content files

Edit portfolio content in:
- `src/data/projects.ts`
- `src/data/skills.ts`
- `src/data/experience.ts`
- `src/data/education.ts`
- `src/data/certifications.ts`
- `src/data/socialLinks.ts`

# Aijaz Portfolio

A clean React + TypeScript + Vite personal portfolio using a simple professional file structure.

## Run

```bash
npm install
npm run dev
```

## Edit content

- Components: `src/components/`
- Projects / skills / experience: `src/data/`
- Styling: `src/styles/`
- Public images: `public/images/`
- CV: `public/resume/`

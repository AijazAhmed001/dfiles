# Aijaz Ahmed — Cinematic Portfolio

Apple-inspired animated portfolio rebuilt from the provided GSAP/Three.js landing page while preserving its visual design and animation components.

## Run

```powershell
npm install
npm run dev
```

Open `http://localhost:5175`.

## Customize

- Portfolio copy and links: `src/constants/index.js`
- Main sections: `src/components/`
- Resume: replace `public/Aijaz-Ahmed-Resume.pdf`
- Project visuals: replace `public/performance1.png` through `performance7.png`
- Videos: replace files under `public/videos/` with your own project footage while keeping the same filenames.

The 3D MacBook models and GSAP scroll animations are preserved.
